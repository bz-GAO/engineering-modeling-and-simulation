# 案例1：大规模制造中的测量装置标定

## 问题概述

课程任务把传感器标定建模为组合优化问题。每个传感器在 $-20\,^{\circ}\mathrm{C}$ 到 $69\,^{\circ}\mathrm{C}$ 的 90 个候选温度点上都有电压响应；实际量产不能逐点标定，因此需要选择少量测量点，在测量成本与插值误差成本之间取得平衡。

总成本由两部分构成：每选择一个标定点产生固定成本 $Q=70$；其余温度点的估计误差按分段规则转换为惩罚。对全部训练样本取平均后得到方案成本。

## 方法

1. 用 90 位二进制染色体表示标定点集合；
2. 对每个传感器样本，以已选点建立三次样条插值关系 $\hat T=f(V)$；
3. 按课程给定的分段误差代价计算适应度；
4. 使用自编遗传算法进行选择、单点交叉和分阶段变异；
5. 对遗传算法的精英解执行相邻位置爬山搜索。

原课程实验曾得到 6 点方案 `[3, 15, 28, 50, 68, 88]`，训练集成本为 471.90、测试集 A 成本为 472.15。这些数值为历史实验记录；算法具有随机性，当前默认的小规模配置不保证得到相同结果。

## 文件

- `src/Ga_Sensor_Calibration.m`：主程序；默认参数是便于检查代码流程的小规模配置。
- `src/eval_cost.m`：课程成本函数。
- `src/mycurvefitting.m`：三次样条插值。
- `src/hill_climbing_search.m`：局部相邻搜索。
- `src/plot_show.m`：收敛与拟合结果可视化。
- `data/README.md`：数据格式和本地放置方式。

## 运行

把两个课程 CSV 文件放入 `data/`，然后运行：

```matlab
run('src/Ga_Sensor_Calibration.m')
```

代码固定随机种子以便比较。若要复现实验报告中的长时间搜索，需要提高种群规模和迭代代数，并进行多次独立运行。

## 局限

- 最优点集依赖训练数据、随机种子和搜索预算；
- 三次样条可能在边界或稀疏区间产生较大误差，因此代码在搜索早期施加边界覆盖约束；
- 目前没有提供遗传算法与穷举、模拟退火等方法的统一基准；
- 课程数据不随仓库提供，运行前需自行取得相应数据。
