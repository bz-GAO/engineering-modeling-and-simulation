# 工程问题建模与仿真：两个课程案例

这是对两项 MATLAB 课程设计的公开仓库整理版。仓库保留可说明建模思路的代码、可复现实验入口和代表性结果；原始提交包、带个人信息的报告、课程任务书以及版权状态未确认的数据集不进入 Git。

> 仓库展示的重点不是代码规模，而是如何把工程描述转换成数学模型、选择求解算法、验证结果并讨论模型边界。

## 内容

```text
案例1/
  README.md
  src/                         遗传算法、三次样条插值和局部爬山搜索
  data/README.md               数据格式与放置说明
案例2/
  README.md
  src/run_quick.m              固定参数快速验证
  src/run_full.m               大样本、全节点规模实验
  results/                     代表性大样本结果
```

## 案例概览

| 案例 | 工程问题 | 数学/计算方法 | 主要结论 |
|---|---|---|---|
| [案例1](案例1/README.md) | 大规模制造中的传感器标定点选择 | 三次样条插值、自编遗传算法、局部爬山搜索 | 在测量成本与标定误差之间寻找低成本的 6 点标定方案 |
| [案例2](案例2/README.md) | 多节点声纳同步时钟机制的可靠性与冗余优化 | 多状态模型、事件驱动蒙特卡洛、能力分桶 | 节点冗余并非越多越好；不同目标对应不同最优规模 |

## 运行环境

- MATLAB R2024b 或兼容版本；
- 案例2不依赖 Statistics and Machine Learning Toolbox，指数分布寿命使用逆变换抽样；
- 案例1需要课程提供的训练集与测试集，数据文件本地保留但默认不进入 Git。
